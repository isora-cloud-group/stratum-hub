## [2.0.0] - 2026-10-28
### Added
- Initial release of `stratum-hub` as the public landing page, master architectural catalog, and unified directory.
- Full architectural blueprints (Tier 0 Ingress to Tier 3 Workloads).
- Universal compatibility matrix covering Python, Node, Spring, Laravel, Overleaf, and Nextcloud.
- Getting started guide with step-by-step orchestrator deployment workflow.
